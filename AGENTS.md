
### Coding Rules
- Write efficient, and minimal code. Avoid unnecessary complexity, duplication, and overengineering.
- Prioritize readability, maintainability, and simplicity.
- For UI development, prioritize smooth interactions, consistent behavior, and a polished user experience.
- Make UI changes robust and reliable, minimizing bugs, glitches, layout issues, and unexpected behavior.
- Prefer simplicity over complex implementations.
- Follow the existing project structure, conventions, and patterns. Avoid unrelated changes and unnecessary refactoring.
- Do not create unnecessary .md files. Use the readme.md for anything that has to be informed
- Keep all comments short, crisp and straight to point. No comments should be too long.
- Do not read files instead temp/. They are not required for the project. It is for my personal use which I will later delete.
- Delete test files after use.
